# Authorship policy

Every cliclo commit must have the author identity `phattbeats <obiwouldjablowme@protonmail.com>` and must contain no `Co-authored-by` trailer, regardless of its name or email. Configure a clone with `git config user.name phattbeats` and `git config user.email obiwouldjablowme@protonmail.com`, then run `./scripts/install-git-hooks.sh` (or `git config core.hooksPath .githooks` directly) so the local commit-msg hook blocks bad commits before they reach GitHub. CI enforces the same rule on every push and pull request via `.github/workflows/authorship-check.yml`. In Claude Code, set `includeCoAuthoredBy` to `false` in user or project `settings.json`; OpenClaw/Paperclip commit paths follow the same rule.
